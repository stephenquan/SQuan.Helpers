# SQuan.Helpers.Maui.Mvvm

`SQuan.Helpers.Maui.Mvvm` provides source-generator helpers that reduce the boilerplate required to add bindable
properties to controls and pages in .NET MAUI. It works alongside
[CommunityToolkit.Maui](https://learn.microsoft.com/en-us/dotnet/communitytoolkit/maui/) and
[CommunityToolkit.Mvvm](https://learn.microsoft.com/en-us/dotnet/communitytoolkit/mvvm/), adding convenient,
strongly typed instance callbacks to bindable properties generated by CommunityToolkit.Maui.

## Description

CommunityToolkit.Maui 14.0.0 introduced the `[BindableProperty]` attribute for generating bindable properties on
.NET MAUI controls. Because CommunityToolkit.Maui now provides the core bindable property generation,
`[BindableProperty]` in SQuan.Helpers.Maui.Mvvm is deprecated and will be removed in a future release.

.NET MAUI bindable property callbacks normally use static methods that receive a `BindableObject` and untyped `object`
values. `[BindablePropertyInstanceMethods]` generates the required static wrappers and forwards each callback to a
strongly typed instance method, removing repetitive casts and boilerplate from your control.

Use `[BindablePropertyInstanceMethods]` with the CommunityToolkit.Maui `[BindableProperty]` attribute and specify a
property-changed, property-changing, or value-coercion callback. For property-changed and property-changing callbacks,
the generator declares partial instance methods that receive either the new value or both the old and new values. You
only need to implement the overloads your control requires.

## Installation

Install SQuan.Helpers.Maui.Mvvm and CommunityToolkit.Maui 14.0.0 or later:

```console
dotnet add package SQuan.Helpers.Maui.Mvvm
dotnet add package CommunityToolkit.Maui
```

Apply `[BindablePropertyInstanceMethods]` together with the CommunityToolkit.Maui `[BindableProperty]` attribute.
Because both packages define a `[BindableProperty]` attribute, use aliases, as shown below, or fully qualify the
attribute names to avoid ambiguity.

## CardView Example

Using `[BindablePropertyInstanceMethods]` with `[BindableProperty]` lets the control handle property changes through a
strongly typed partial instance method instead of a static callback that requires casts.

```c#
using BindablePropertyAttribute = CommunityToolkit.Maui.BindablePropertyAttribute;
using BindablePropertyInstanceMethodsAttribute = SQuan.Helpers.Maui.Mvvm.BindablePropertyInstanceMethodsAttribute;

public partial class CardView : ContentView
{
    [BindableProperty(PropertyChangedMethodName = nameof(OnCardTitleChanged))]
    [BindablePropertyInstanceMethods]
    public partial string CardTitle { get; set; } = string.Empty;

    partial void OnCardTitleChanged(string oldValue, string newValue)
    {
        System.Diagnostics.Trace.WriteLine($"CardTitle changed from '{oldValue}' to '{newValue}'");
    }

    [BindableProperty(PropertyChangedMethodName = nameof(OnCardDescriptionChanged))]
    [BindablePropertyInstanceMethods]
    public partial string CardDescription { get; set; } = string.Empty;

    partial void OnCardDescriptionChanged(string oldValue, string newValue)
    {
        System.Diagnostics.Trace.WriteLine($"CardDescription changed from '{oldValue}' to '{newValue}'");
    }

    public CardView()
    {
        InitializeComponent();
    }
}
```

## Count Example

You can use `[BindableProperty]` and `[BindablePropertyInstanceMethods]` to quickly add bindable properties to your
.NET MAUI controls and pages.
The source generators will reduce the code needed to add properties.

The following example turns `Count` into a bindable property and adds a property-changed callback that reacts to
changes in the `Count` property.

```c#
using CommunityToolkit.Maui.Markup;
using BindablePropertyAttribute = CommunityToolkit.Maui.BindablePropertyAttribute;
using BindablePropertyInstanceMethodsAttribute = SQuan.Helpers.Maui.Mvvm.BindablePropertyInstanceMethodsAttribute;
using RelayCommandAttribute = CommunityToolkit.Mvvm.Input.RelayCommandAttribute;

public partial class MainPage : ContentPage
{
    [BindableProperty(PropertyChangedMethodName = nameof(OnCountChanged))]
    [BindablePropertyInstanceMethods]
    public partial int Count { get; set; } = 0;

    partial void OnCountChanged(int oldValue, int newValue)
    {
        System.Diagnostics.Trace.WriteLine($"Count changed from '{oldValue}' to '{newValue}'");
    }

    public MainPage()
    {
        BindingContext = this;
        InitializeComponent();
        CounterBtn.Bind(
            Button.TextProperty,
            static (MainPage ctx) => ctx.Count,
            stringFormat: "Clicked {0} times");
    }

    [RelayCommand]
    void IncrementCounter()
    {
        Count++;
        SemanticScreenReader.Announce(CounterBtn.Text);
    }
}
```
