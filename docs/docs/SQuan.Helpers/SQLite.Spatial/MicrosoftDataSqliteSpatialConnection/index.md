# MicrosoftDataSqliteSpatialConnection Class

The MicrosoftDataSqliteSpatialConnection is a wrapper for [Microsoft.Data.Sqlite](https://www.nuget.org/packages/Microsoft.Data.Sqlite) SqliteConnection with spatial functions added.
