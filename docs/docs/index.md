# Welcome

Hi, I'm Stephen Quan, a Principal Software Development Engineer at [Esri](https://www.esri.com/) based in Melbourne, Australia. I work on Esri's field data collection products, including [ArcGIS Survey123](https://survey123.arcgis.com/) and [ArcGIS QuickCapture](https://www.esri.com/en-us/arcgis/products/arcgis-quickcapture/overview), helping build next-generation solutions with .NET and .NET MAUI.

## Community projects

In my spare time, I build and maintain a number of open source libraries published on NuGet.org. These projects began as solutions to problems I encountered in my own work, but have since evolved into tools that contribute to the broader .NET and .NET MAUI communities.
